# 卒業制作

ネットワーク・セキュリティ分野の卒業制作を進めるための授業教材です。テーマ発見から環境構築、開発、論文執筆、発表までの一連の流れを、全17回の授業に沿って解説します。

## 目的

1年半の学習成果をもとに、ネットワークセキュリティ上のテーマを発見し、その解決を実習結果から考察・追求する。

## 到達目標

- 興味あるテーマを自主的に発見し、その意義・実現可能性を具体的に説明できること。
- 解決のための環境を構築できること。
- 実験結果を適切に説明できること。
- 作業経緯を指示に従い客観的にわかる報告書にまとめ、合格判定されること。

## 提出物

計画書・スケジュール・週次報告書は、教材リポジトリの **Markdown テンプレート**をコピーして記入し、各自のリポジトリで git 管理します。卒業論文テンプレートと手引きは、Word 形式で Google ドライブの指定フォルダにあります。

- **卒業制作計画書**（[テンプレート](./templates/卒業研究計画書テンプレート.md)） — 制作を始める前に、これから制作する内容をまとめて提出する。
- **卒業制作スケジュール**（[テンプレート](./templates/卒業制作スケジュールテンプレート.md)） — 制作を始める前に、週ごとのスケジュールを提出する。以降、進み方に合わせて毎週更新する。
- **週次報告書**（[テンプレート](./templates/週次報告書テンプレート.md)） — 週ごとの進捗状況をまとめて提出する。必ず毎週提出すること。
- **卒業論文テンプレート**（Word） — 卒業論文の原稿を作成する際に利用するテンプレート。コピーして利用する。
- **卒業論文執筆の手引き**（PDF） — 卒業論文の書き方についての手引き。
